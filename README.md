# SPECTRE-9 // Hacker Terminal

A cinematic, **100 % simulated** hacker terminal & hacker-typer web experience — now an
[Astro](https://astro.build) static site for maximum SEO, fast first paint, and zero-runtime
cost on Cloudflare Pages.

> No backend, no network code, no real hacking: every node, packet, hash and “breach” is
> generated locally in the browser as pure visual theatre. See [`PROJECT_OVERVIEW.md`](./PROJECT_OVERVIEW.md)
> for the full feature matrix (commands, tools, modes, safety guarantees).

---

## Quick start

```bash
npm install
npm run dev        # http://localhost:4321
```

## Scripts

| Script | What it does |
|---|---|
| `npm run dev` | Astro dev server with live reload |
| `npm run build` | Production build → `dist/` (static HTML/CSS/JS + sitemap) |
| `npm run preview` | Serve the built `dist/` locally |
| `npm run og` | Regenerate `public/og.png` from the page `<h1>` (sharp) |
| `npm run smoke` | Playwright smoke suite — 20 checks incl. SEO, a11y, overflow (`tools/smoke.mjs`) |
| `npm run deploy` | Build + `wrangler pages deploy dist` to the existing Pages project |
| `node tools/probe.mjs` | Layout diagnostics: bounding boxes/overflow dumps at 390–1600 px, screenshots in `tools/shots/` |

## SEO

- Per-page `<title>`, meta description, canonical link, `robots` meta.
- Open Graph + Twitter card tags, `og.png` preview (1200×630).
- JSON-LD: `WebApplication` + `FAQPage` (the Mission Brief content — `?` key opens it).
- `sitemap-index.xml` generated by `@astrojs/sitemap`.

The site URL used for canonical/OG/sitemap comes from `site` in `astro.config.mjs` and can be
overridden per-build with the `SITE_URL` environment variable:

```bash
SITE_URL=https://yourdomain.com npm run build
```

## Deploying to Cloudflare Pages

1. Push this repo to GitHub/GitLab (or use direct upload).
2. In Cloudflare Pages → **Create project → Connect to Git**, pick the repo.
3. Build settings:

   | Setting | Value |
   |---|---|
   | Framework preset | **Astro** |
   | Build command | `npm run build` |
   | Build output directory | `dist` |
   | Node.js version | `20` or later (set in *Environment variables* as `NODE_VERSION=20` if needed) |

4. Optional environment variable: `SITE_URL=https://your-domain.pages.dev` — only needed if
   the canonical domain changes (e.g. custom domain).
5. Deploy. `public/_headers` is picked up automatically and adds
   `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy` and a CSP.
   The 404 page (`/404.html`) is served automatically for unmatched routes.

The repo already includes a working `wrangler` one-liner for CLI deploys:

```bash
npm run deploy     # astro build && wrangler pages deploy dist --project-name=hacker-terminal --branch=main
```

## Testing

```bash
npm run smoke        # 20/20 checks: SEO head, globals, boot, brief modal, themes,
                     # no horizontal overflow @1440 & @390, mobile panes, console/page errors
node tools/probe.mjs # geometry dump + screenshots at 390 / 768 / 1024 / 1440 / 1600
```

Both require Chrome/Chromium via Playwright (`npx playwright install chromium` if missing).
